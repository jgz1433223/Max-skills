# max-experience-deepdive · 项目经历深挖

> 把「我做了什么」挖成「我为什么这么做」，再用**这位面试官**听得懂的话讲出来。

[max 系列](../README.md) 的一员。你给出一段自己的项目经历，再告诉它面试官是谁，它会帮你：

1. **诊断**：这段经历停在第几层，哪句话被你埋没了。
2. **挖深度**：找出经历里的岔路口，挖出你当时的取舍和判断。
3. **按面试官做术语审计**：判断哪些概念他肯定懂、可以直接说，哪些要轻带一句，哪些必须翻译成大白话。
4. **产出两个版本**：
   - **版本一：初次介绍**。约 45 秒，讲清楚做了什么，留 2 到 3 个钩子引导面试官追问。
   - **版本二：深度知识库**。按这位面试官可能问的问题组织，用来接住每一次追问。

## 核心理念

- **深度 = 讲出别人替你说不出来的「为什么」。** 做了什么谁都能写；当时怎么选、凭什么选、以后会不会这么选，才是你。
- **深度 ≠ 深奥。** 用理论和术语解释「为什么」，往往说明还没想透。能用对方听得懂的话让他很快 get 到，才证明想透了。
- **听得懂取决于听的是谁。** 对 HR 要翻译的词，对同行直接说；对同行还翻译，反而显得不专业。
- **面试是对话，不是演讲。** 先讲简单版并留钩子，深度内容等面试官来问。

## 使用

**必须提供两项输入，缺任何一项，Skill 都只会追问，不会开始输出：**

```
帮我深挖这段项目经历。

【项目介绍】<项目背景：做什么的、为什么做> + <你具体做了什么>

【面试官身份】<岗位或职能：HR / 业务负责人 / 同岗位同行 / 技术负责人 …> + <行业或团队>（可选：面试轮次或职级）
```

选填：目标岗位、使用场景（面试、晋升、简历）、时长限制。

拿到结果后，补上待补清单里的真实事实，再让 Agent 重新生成一遍。

## 效果对比

**原版**（停在动作层）：
> 我参与搭建评测体系，从要素齐全度和质感两个维度评测，输出报告反馈给算法，帮助他们优化迭代。

**版本一**（面试官：不做 AI 的产品总监）：
> 这个功能是：用户挑一个做好的海报样式，换上自己的照片，就能出一张同款，我们想让 AI 自动生产这些样式。我负责检查 AI 做出来的样式能不能用。检查标准我只定了两条。发现问题后，我没有让工程师马上去重新训练模型，而是先让他们把同样的图多跑几轮……

**同一句话，对不同面试官的说法：**

| 面试官 | 说法 |
|---|---|
| HR | 先让 AI 把同样的图多做几次，确认它是真的不会，再决定要不要花大成本给它专门补课 |
| 算法负责人 | 生成有随机性，所以先多跑几轮看问题是否稳定复现，再决定要不要上 SFT |

完整示例见 [examples/ai-template-eval.md](examples/ai-template-eval.md)。

## 安装

把 `max-experience-deepdive` 文件夹放进你所用 Agent 的 skills 目录，例如：

```bash
git clone https://github.com/jgz1433223/Max-skills.git
# Claude Code
cp -r max-skills/max-experience-deepdive ~/.claude/skills/
# 其他支持 SKILL.md 格式的 Agent，放到对应的 skills 目录即可
```

## 目录结构

```
max-experience-deepdive/
├── SKILL.md                    # 主流程：输入关卡 + 6 步工作流 + 硬规则 + 常见错误
├── references/
│   ├── depth-model.md          # 四层模型、三个自检测试、深度 vs 深奥
│   ├── jargon-audit.md         # 按面试官身份做术语审计 + 常见术语翻译表
│   ├── hook-design.md          # 钩子的定义、类型、规则、反例
│   └── question-bank.md        # 面试追问题库（A 到 G 七类）
├── templates/
│   └── output-template.md      # 输出模板
└── examples/
    └── ai-template-eval.md     # 完整示例（含输入关卡追问）
```

## 硬规则

- 没有项目介绍和面试官身份，就不输出。
- 绝不编造事实。缺失的信息一律写成 `[待补：…]`。
- 推测必须标注 `⚠️推测`。
- 深挖版不能比原版更难懂。
