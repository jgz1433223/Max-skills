# 深度模型：什么是「讲出深度」

## 1. 常见误解

多数人以为「讲出深度」是在表达上加东西：

| 误解 | 实际做的事 | 为什么不是深度 |
|---|---|---|
| 讲得更细 | 加长度 | 细节仍然是动作 |
| 强调有多难 | 加难度 | 难度是环境的属性，不是你的 |
| 最后拔高意义 | 加高度 | 「让我学会了团队协作」谁都能说 |
| 用理论解释 | 加深奥 | 只是给现象起名字，不是解释 |

## 2. 听的人到底要什么

| 谁在听 | 他说「有深度」时，实际想要什么 |
|---|---|
| 面试官 | 能从这段经历**预测你下次会怎么做** |
| 晋升评委 | 你是在更大范围里定义问题，还是只完成了任务 |
| 普通听众 | 听到一个没想到、但一想就对的判断 |

问题出在错位上：听的人要的是**预测力**，讲的人给的却是**信息量**。

## 3. 四层模型

| 层 | 回答的问题 | 别人能替你说吗 |
|---|---|---|
| L1 动作 | 我做了什么 | 能，换任何人都这么写 |
| L2 取舍 | 当时有哪几条路，为什么没选另外几条 | 难 |
| L3 判断依据 | 我凭什么认知做的选择，哪些后来证明是错的 | 不能 |
| L4 可迁移规则 | 换个场景这条判断还成立吗，边界在哪 | 不能，这是你独有的 |

只讲 L1 叫「做了什么」，讲出 L2 到 L4 才叫深度。L4 最值钱，因为面试官可以用它预测你的下一次行动。

## 4. 三个自检测试

1. **反事实测试**：换一个普通人来做，结果会有什么不同？说不出来，说明这段经历里只有岗位的痕迹，没有你的痕迹。
2. **迁移测试**：听的人能不能拿你的结论，去推断另一个场景该怎么做？
3. **可证伪测试**：结论有没有边界，有没有可能是错的？一句永远正确的话，等于什么都没说。

## 5. 深度和深奥是两件事

|  | 用大白话讲 | 用深奥的话讲 |
|---|---|---|
| **挖到底了** | ✅ 真深度：一听就懂，懂了还觉得有收获 | 想透了，但没翻译成听众的语言 |
| **没挖到底** | 浅白：「沟通很重要」 | ❌ 假深度：用术语包装一句正确的废话 |

- 深度衡量的是**想**：在「为什么」上挖了几层。
- 深奥衡量的是**说**：听的人要付出多少理解成本。

### 为什么用理论解释，往往说明没想透

理论常常只是给现象起名字：

- 「用户不买单，因为没占领用户心智。」
- 「增长很快，因为跑通了飞轮。」
- 「我是基于第一性原理做的决定。」

把术语换成大白话，句子要么塌掉，要么变成一句谁都知道的话。术语让「为什么」停在了半路，听起来却像已经走到了底。

### 为什么大白话能证明你想透了

想用大白话讲清楚一件事，你必须把它拆到**对方已经有的经验**为止。拆不到这一步，你就只能借一个现成的术语把空白盖住。

- 会用术语，说明你知道这件事叫什么。
- 能讲成大白话，说明你知道它是怎么回事。

### 怎样让人很快 get 到

1. **锚在对方经历过的事上**，不要让对方先学一个新概念。
2. **因果一步一跳**，不省略中间步骤。
3. **给具体场景**，不停留在抽象原则。

### 边界：术语什么时候可以用

对同行来说，术语是**压缩**，不是遮掩。判断标准不是用没用术语，而是**能不能随时把它展开成大白话**：能展开，术语是压缩包；展开不了，术语就是遮羞布。

## 6. 这是 Question 还是 Problem

「怎么讲出深度」看起来是个表达技巧问题（Question），好像有模板可以套。但讲不出深度，九成原因是**没有可讲的东西**：当时没意识到自己在做选择，事后也没有复盘出规则。

所以讲之前要先做一件事：**把经历里的岔路口一个个找出来，写下当时选了什么、没选什么、为什么。**

## 7. 一句话

> 做了什么，是简历上的字；为什么这么做、以后还会不会这么做，才是你。越深的道理，越是大白话。
